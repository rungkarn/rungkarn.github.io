Label Merge

ได้ label CSV ใหม่จากทีม หรือมี override ใหม่

โค้ด: tool/label_merge/ (module)

dry-run (ไม่เขียนอะไร) 
L=/project/lt200264-saiwat/WormProject/data/worm-24022026/labels

python -m tool.label_merge \
    --base $L/worm-24022026-labels_current.csv \
    --input $L/<ไฟล์ใหม่>.csv
เขียนจริง 
python -m tool.label_merge \
    --base $L/worm-24022026-labels_current.csv \
    --input $L/<ไฟล์ใหม่>.csv \
    --out-dir $L --write

กลไก merge 6 ชั้น

ชั้นทำอะไร
0. gateตรวจ index basis ต่อภาพ (SAM2 vs SAM3)
1. exclusionsตัดตาม label_exclusions.csv
2. lineageเลือกไฟล์ใหม่สุดของแต่ละสาย (nb, pc)
3. authorityภาพนี้ใครเป็นเจ้าของ
4. overrideslabel_overrides.csv + per-user (latest row wins)
5. additionsตัวแถมจาก pkl (src="extra")
6. writesnapshot + manifest → ขยับ symlink
ชั้นที่ตัดของทิ้งโดยไม่พิมพ์จำนวน = จุดที่ข้อมูลผิดเข้ามาแบบเงียบ

ผลลัพธ์

  • worm-24022026-labels_<date>_<N>images.csv — snapshot ใหม่
  • decisions_<date>.csv, review_<date>.csv
  • segfail_pairs_<date>.csv, reseg_queue_<date>.csv
  • symlink labels_current.csv → snapshot ล่าสุด

python -m unittest tool.test_label_merge    # 34 tests

Final Select

หลัง merge เสร็จ หรือ pkl เปลี่ยน (reseg ทำ mask เปลี่ยน)

โค้ด: tool/label_merge/final_select.py

ผ่าน SLURM (16 cores, ~1 ชม.) 
cd /project/lt200264-saiwat/WormProject

sbatch code/slurm/run_final_select.sh \
    /project/lt200264-saiwat/WormProject/data/worm-24022026/final \
    --tag <YYYYMMDD>

สิ่งที่ทำ

  1. อ่าน labels_current.csv + pkl ทุกภาพ
  2. Deduplicate ด้วย pixel-level IoU NMS
  3. Filter ตาม bUse (ตัด bUse=0,7)
  4. แปลง bUse=6 → class 3 (Undecidable)
  5. แยก output เป็น 3 กลุ่ม: train, noise, missseg

ผลลัพธ์ (8 ไฟล์ ใน final/)

ไฟล์จำนวนคืออะไร
final_<tag>.csv~174Klabel สำหรับเทรน (class 0,1,2,3,6)
_detail.csv~174Klabels + metadata ครบ
_dropped.csv~59Kmask ที่ถูกตัดออก พร้อม reason
_noise.csv~35Kclass 4 (Not worm)
_noise_detail.csv~35Knoise + detail
_missseg.csv~16Kclass 5 (Miss-seg)
_missseg_detail.csv~16Kmissseg + detail
_summary.txt—สรุปตัวเลขทุกขั้นตอน

Build Release

หลัง final_select เสร็จ

โค้ด: pipeline/build_release.py

ผ่าน SLURM (32 cores, ~10 นาที, CPU only) 
cd /project/lt200264-saiwat/WormProject
sbatch code/slurm/run_build_release.sh

สิ่งที่ทำ

  1. รวม final + noise + missseg CSV เป็นไฟล์เดียว
  2. อ่าน pkl ทุกภาพ → resolve boundary, bbox, area, instance_id
  3. ตรวจ QC (missing_pkl, row_out_of_range, decode_fail, suspect_index)
  4. เขียน instances.parquet + images.parquet + manifest.yaml

คำสั่งเบื้องหลังใน SLURM script

# รวม CSV
head -1 "$FINAL" > "$COMBINED"
tail -n+2 "$FINAL" >> "$COMBINED"
tail -n+2 "$NOISE" >> "$COMBINED"
tail -n+2 "$MISSSEG" >> "$COMBINED"

# Build
python -m pipeline.build_release \
    --csv          "$COMBINED" \
    --masks-dir    "$ROOT/processed/segmentation_masks" \
    --images-dir   "$ROOT/raw" \
    --roi-mask-dir "$ROOT/processed/cropped/roi_mask" \
    --out          "$REL" \
    --workers 32

ผลลัพธ์

ไฟล์คืออะไร
instances.parquetทุก instance: instance_id, image_id, class, bbox, boundary (RLE), area, score, qc_status
images.parquetข้อมูลภาพ: image_id, width, height, path
manifest.yamlprovenance: label path, masks path, sha256, build date, row counts

Build Views

หลัง build_release เสร็จ

โค้ด: pipeline/build_crops.py + pipeline/export_view.py

ผ่าน SLURM (32 cores, ~6 ชม.) 
cd /project/lt200264-saiwat/WormProject
sbatch code/slurm/run_build_views.sh

6a. Crops — 3 background variants

for bg in raw blackout dim; do
    python -m pipeline.build_crops --release "$REL" \
        --images-dir "$RAW" --bg-mode "$bg" \
        --workers 32 --skip-existing
done
bg-modeผลลัพธ์crop dir
rawภาพจริงรอบ mask, pad 30 pxcrops/pad30_raw/
blackoutเฉพาะ mask บนพื้นดำ, pad 0crops/pad0_blackout/
dimmask ชัด + background จางcrops/pad30_dim0p3/

6b. Segmentation views (COCO + YOLO)

# Binary worm (1 class) — COCO
python -m pipeline.export_view --release "$REL" \
    --space binary_worm --format coco \
    --out "$REL/views/coco_binary"

# 4-class segmentation — COCO
python -m pipeline.export_view --release "$REL" \
    --space seg_cls4 --format coco \
    --out "$REL/views/coco_cls4"

# Binary worm — YOLO
python -m pipeline.export_view --release "$REL" \
    --space binary_worm --format yolo_seg \
    --out "$REL/views/yolo_seg_binary"

6c. Classification views (ImageFolder)

# cls2 × 3 background variants (Phase 1+2)
for variant in pad30_raw pad0_blackout pad30_dim0p3; do
    python -m pipeline.export_view --release "$REL" \
        --space cls2 --format imagefolder \
        --out "$REL/views/cls2_${variant}" \
        --crop-variant "$variant"
done

# cls4, cls5 (Phase 3)
for space in cls4 cls5; do
    python -m pipeline.export_view --release "$REL" \
        --space "$space" --format imagefolder \
        --out "$REL/views/${space}_raw" \
        --crop-variant pad30_raw
done

6d. Noise filter + Miss-seg views

# Noise filter: worm vs non_worm
python -m pipeline.export_view --release "$REL" \
    --space noise_filter --format imagefolder \
    --out "$REL/views/noise_filter_raw" \
    --crop-variant pad30_raw

# Miss-seg detection: good_seg vs missseg
python -m pipeline.export_view --release "$REL" \
    --space missseg_detect --format imagefolder \
    --out "$REL/views/missseg_detect_raw" \
    --crop-variant pad30_raw
